# little-proxy

[![CI](https://github.com/DiamondDen/little-proxy/actions/workflows/ci.yml/badge.svg)](https://github.com/DiamondDen/little-proxy/actions/workflows/ci.yml)

Крошечная программа для Windows: заворачивает TCP-трафик выбранных процессов в SOCKS5 или HTTP
прокси. Процессы выбираются регулярными выражениями по полному пути exe, без учёта регистра —
`\claude[^\]*\.exe$` поймает и `C:\…\claude.exe`, и `D:\old\claude32521353-old.exe`.

- Один exe без зависимостей: копируется на любую Windows 10/11 x64 (не ARM) и сразу работает.
  Папка с exe должна быть доступна на запись.
- Запуск — от администратора (запрос UAC появится сам). Рядом с exe распакуются `WinDivert.dll`
  и `WinDivert64.sys`, настройки сохраняются в `little-proxy.ini`.
- Прокси задаётся одной строкой: `socks5://логин:пароль@хост:порт` или `http://логин:пароль@хост:порт`
  (логин и пароль необязательны, без схемы считается SOCKS5). Купить прокси можно, например, на
  [proxy6.net](https://proxy6.net/?r=997240).
- Можно указать и домены: HTTP/HTTPS любой программы к домену и его поддоменам пойдёт через
  прокси. Адреса доменов берутся из ответов DNS, поэтому зашифрованный DNS (DoH/DoT) при этом
  блокируется — браузеры и Windows переходят на обычный. Открытые до запуска соединения идут
  напрямую: после запуска перезапустите браузер.
- Свёрнутое окно уходит в трей: левый клик по значку открывает окно, правый — меню
  (запуск/остановка, выход). Крестик при работающем перехвате тоже прячет окно в трей (закрыть —
  «Выход» в меню), а при остановленном — просто закрывает программу.
- UDP целевых процессов блокируется, уже открытые соединения сбрасываются — напрямую не уходит
  ничего.
- Для HTTPS имя хоста берётся из TLS SNI и передаётся прокси, поэтому DNS прокси тоже работает.

Сборка: `cargo build --release`. WinDivert © basil00, LGPLv3 (`vendor/windivert/LICENSE`).
